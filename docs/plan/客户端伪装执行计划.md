# /codex 客户端伪装执行计划

将客户端伪装做成 Provider 可独立开启的功能：每个上游登录实例拥有稳定的虚拟设备身份，同账号的不同登录实例使用独立身份，同时保留不同下游客户端、会话、线程和请求的语义。当前接入点为 `/codex`，覆盖 HTTP 与 WebSocket 链路。

登录实例指持久化凭据记录 `credentialsession.Session.ID`，不是下游请求头 `Session-Id` 或上游账号 ID。下游默认按入口 API Key 区分持久客户端身份；换 Key 默认形成新身份，显式绑定原身份后，伪装映射、旧对话归属、恢复及粘性一并延续。功能以身份一致性和使用体验为目标，现有材料不足以证明伪装能避免额度缩减。

## 已确定的行为

- Provider 独立开关，默认关闭，不按账号联动。设备身份与档案绑定登录实例：共用同一凭据记录的 Provider 共享身份与档案，但开关互不影响；同账号的不同凭据记录独立生成身份、管理档案。
- 设备身份不随 Token 刷新、原记录内的同账号重新认证、共用该记录的 Provider 切换或服务重启变化。新增登录记录生成新身份；原记录改换账号时重建身份绑定。
- 内置按客户端类型（Desktop、TUI、CLI 等）、平台、架构区分的默认档案。未绑定的登录实例在候选阶段仅推导匹配档案，确定发送目标后、发送前原子持久化；并发请求及共用凭据的 Provider 复用最终绑定，提交结果与候选推导不同时按平台规则重新筛选。无法识别时保持未绑定，以档案不可用为由排除候选并说明原因，不归为转换故障。绑定后类型、平台、架构不自动切换，可在设置手动修改。
- 客户端版本号与档案修订号分开。默认自动跟随：指定参考客户端出现同类型、同平台、同架构的较新版本，或同版本的 Desktop build、系统小版本、UA 等特征变化时，新建并使用档案修订，保留旧修订。旧版本不触发降级；同版本样本按同一参考来源的原始采集时间排序并按特征去重，迟到或重复样本不推动当前修订；无新样本时继续使用当前档案。支持导入、选择客户端版本与档案修订；固定模式锁定具体修订，手动回滚同时切入固定模式，恢复自动跟随后才继续更新。
- 新 HTTP 逻辑请求和新下游 WebSocket 连接（含断线重连恢复）采用当前配置与档案；同一请求／连接内，对同一 Provider 与登录实例沿用原快照，内部重试不更新。历史对话可直接使用新版特征继续，升级仅更新样本中实际变化的字段，不重建设备与会话映射；只有 UA 变化时不连带修改其他特征。
- 开关变化按上述请求／连接边界生效，不清空身份、映射或对话归属。关闭时保留原始客户端身份字段，再次开启复用原映射；共用凭据但开关不同的 Provider 之间切换仍遵循现有连续性规则，不因模式变化主动新建对话。
- 学习内容是客户端版本和环境特征，设备 ID 由网关独立生成，会话标识与请求内容不进入共享档案。协议能力仍按实际链路协商。
- Provider 启用伪装后，平台匹配默认开启且可独立关闭。开启时，明确不匹配或平台信息冲突的候选被排除；未知平台默认排除，可在设置中单独改为允许使用当前档案。以原始 UA 的明确平台信息为主，其他明确的平台字段补充；WSL 报告 Linux 按 Linux，报告 Windows 按 Windows。
- 平台判断不检查工作区路径、提示词或工具输出，不要求正文所有路径属于同一系统。真实路径保留，仅对明确属于遥测用途的元数据提供可选映射。
- 转换失败先记录详细诊断，再拦截本次逻辑请求并返回可定位的错误；已开始发送则终止本次发送。不得原样放行、部分降级或通过自动重试／切号绕过。此类错误归属网关转换实现，不计入上游健康失败，保留证据供修复代码。

## 身份语义

| 对象 | 处理方式 |
| --- | --- |
| 安装／设备 ID | 每个登录实例固定一个独立的随机 UUIDv4，不依赖下游 installation ID，不按上游账号 ID 合并。 |
| 会话、线程、轮次 | 按登录实例与持久客户端身份稳定映射，保留各自粒度及已知关联，不把不同对话合并。 |
| 请求 ID | 保持逻辑请求及其重试的关联，不复用线程 ID 充当所有请求 ID。 |
| 窗口 ID | 映射所属线程并保留上下文窗口代际，不统一改成 `:0`。 |
| `prompt_cache_key` | 默认保留；提供稳定重映射能力，保持客户端原有缓存分组关系。 |
| 上游账号头、响应引用、Turn State | 继续由凭据和连续性机制管理，不作为普通客户端标识任意重写。 |

`prompt_cache_key` 具有缓存分组和路由意义，不能直接当作通用会话 ID：[OpenAI 缓存说明](https://developers.openai.com/api/docs/guides/prompt-caching)。修改客户端标识也不能替代响应引用的连续性处理：[OpenAI WebSocket 说明](https://developers.openai.com/api/docs/guides/websocket-mode)。

## 执行顺序

1. **建立登录身份与客户端档案模型。** 复用凭据会话及 Provider 绑定，按登录实例持久化设备身份与档案绑定，Provider 单独保存开关、平台匹配及未知平台策略；同账号多次登录不自动合并。伪装身份与账号主体、UpstreamAuthority 分离，保留上游连续性边界。建立统一客户端身份解析接口，替代伪装、连续性、恢复及粘性各自直接按原始 Key 派生作用域的做法；显式 Key 绑定须能解析并延续既有对话归属。

2. **统一平台筛选与出站转换。** 从原始入口数据投影平台事实，将匹配规则接入统一候选筛选，覆盖 HTTP／WebSocket、粘性命中、重试及故障切换。对开启平台匹配的 Provider，按平台判定及未知平台策略保留或跳过，保留现有路由排序与连续性约束；无可用候选时返回包含平台排除原因的错误，不记上游健康失败。连续性与归属判断使用原始客户端语义，物理发送使用筛选时的配置与档案快照派生的载荷。同步重构 WebSocket replay／permit，保留原始消息与协议决定；首发及重放均从原始数据按目标快照生成，切换 Provider 或登录实例不得沿用上一目标的派生载荷，不扩大现有重试及切换范围。平台不匹配属于正常筛选，转换失败仍记录详细诊断并拦截本次请求。

3. **实现字段级转换与还原。** 同步处理 Header、HTTP JSON、WebSocket 消息及内部序列化的 turn metadata，保证跨载体一致。`/models`、`/alpha/search` 等非对话请求按各自协议应用适用的客户端特征与身份转换，保留原方法、查询参数及业务载荷语义；不要求对话字段，不因无正文、非对话结构或无适用转换字段判为失败，平台筛选仍按统一规则生效。保留未知字段和未修改片段；响应只在已确认的协议位置还原，不做全文替换。梳理 HTTP 入口对完整语义投影的等待，仅消除不影响选路、归属及跨载体映射的等待；条件满足时流式转换并提前发送，确需完整正文时仍先完成转换。不因开启功能统一全量缓冲。后续解析或编码失败立即终止。正文、编码、长度及重放来源统一交给发送层，保留取消与 reader 生命周期。未知事件按原协议转发；已知事件中协议允许的身份字段缺失或空值也保留原语义，例如预热请求的空 `turn_id`，不误判为转换失败或凭空补建会话、轮次。

4. **接入档案学习与传输特征。** 从指定参考客户端学习同类型、同平台、同架构的版本与环境信息，按实际样本保存 UA、Originator 等特征以及来源、采集时间、客户端版本与档案修订号；特征变化生成新修订，按跟随设置切换，按上述请求／连接边界绑定快照。TLS／HTTP 特征依据独立传输样本接入 `upstreamtransport` 和 WebSocket 拨号，不能由 UA 推断或将 Chrome TLS 模板视为 Codex 的完整特征。连接池按实际传输配置隔离；不因开启伪装自动增加 Cookie 或改写 Accept-Encoding。

5. **集中设置与诊断。** 独立“客户端伪装”页管理登录身份、客户端类型、参考来源、客户端版本与档案修订选择及自动跟随／固定模式；展示采集时间及共用档案的 Provider。Provider 页面保留开关、生效摘要、平台匹配和未知平台策略及编辑入口；摘要说明平台排除和转换失败终止，平台无可用候选时提供对应设置入口。凭据页面展示身份绑定及跳转；备份界面列明恢复范围，并提前说明配置导入新环境后 ChatGPT 登录需重新认证。高级设置承载 Key 绑定、缓存键与遥测路径映射、传输特征。分别展示标识转换、档案与传输特征的生效范围；记录候选平台判定、原始依据及排除原因。请求／尝试关联 Provider、登录实例、账号、客户端版本、档案修订号、映射身份与转换决定；失败时保留阶段、字段位置、错误链及可复现的原始／派生片段。支持字段差异查看，客户端错误附带诊断关联 ID。

6. **贯通生命周期行为。** 覆盖首次自动绑定及并发共享、平台未知的默认排除与可选允许、明确冲突、WSL 及各路由入口；同账号多登录、开关变化及共用凭据的跨模式 Provider 切换；HTTP／WebSocket 切换、内部重试冻结与重连采用当前档案；同类型新版及同版本特征更新、固定／回滚与恢复跟随、客户端升级后历史对话继续；重新认证、Token 刷新及显式 Key 绑定后旧对话恢复。登录身份、档案、各类绑定及对话归属纳入持久化与备份恢复，独立保留身份绑定的账号依据；恢复原记录后，同账号重新认证自动复用身份，换账号按既定规则重建，保留旧对话记录。覆盖导入已有同 ID 记录的合并与冲突处理，不新增身份恢复确认步骤。覆盖正常预热及标识缺失／空值、转换失败拦截、诊断及取消恢复；大正文首包延迟与原链路对照验收。
